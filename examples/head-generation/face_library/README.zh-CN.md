## 研究依据与边界

见 literature-review.zh-CN.md、research-conclusions.zh-CN.md 及 research-index.json。
358 条六游戏正侧参考已重新目视检查，348 条可作粗粒度人形下脸归纳，7 条遮挡或局部缺失，3 条特殊兽形/机械外观另列。另有23对独立复核，揭示尖/圆和长短标签含义不一致，因此不把临时描述标签的频数当作自然脸型分布。

这些主要是第三方模型参考渲染，不是认证官方网格；源图大多头顶/后脑截断。本库只处理可见下脸，不依据发型推测额宽、发际线或颅形。仓库仅保留来源索引和文字观察，不包含第三方参考图片或模型。

## 创作入口

保留原有8个脸部选择，新增4个入口，但不是新增4个科学造型族：
- research-compact-rounded：紧凑圆弧观感，较丰满的下颊和较宽圆颏。
- research-soft-tapered：连续柔和收束至小颏。
- research-straight-tapered：较直的下颊斜段和较窄的收束。
- research-blunt-chin：短钝颏变体，不将其宣传为普遍方脸。

共有一个连续轮廓构造核心。jaw_fullness 控制下颊/下颌丰满度；chin_roundness 调整末端两个宽度站点，并在圆弧样式下联动三维下颏回折的有界垂直弧度，不混同整体收束；chin_projection 控制侧面下颏的低幅度前后支撑。范围是工程作者设定，不是由截图推算的毫米值。独立纵向脸长、全头壳、兽头毛发或机械面板尚未实现。

保留旧配方、旧默认选择及不可变基底。新设计拒绝与旧脸部宽度控制/模板混用；参数、源码摘要和校准曲线绑定到组合快照、实际生成回执及后续 SDF 检查。

## 几何约束

- 新轮廓在原12毫米半宽模板域内，使用与运行时一致的谐和斜率三次插值凸包界。
- h≥0.45 的整个宽度插值段保持不变，不只是站点值不变。
- 侧面前向剖面限制2毫米；这是该剖面插值的界，不是固定 x 下全表面位移或全局无碰撞证明。
- 额头、眼部参数和现有其他五官选择不被脸型控制改写；实际共享曲面/接缝仍需原生检查。
- 保留并启用下颌轮廓回退守卫，耳根约束采用已有轮廓输运构造，不放宽原位移、法线和拓扑门限。

## 使用与验收

六槽选择文件的 face 字段选上述 ID；face_components/plan.py 与 bundle.py 均接受 --face-controls JSON 文件，计划和生成应具有相同的组合摘要。沿用生成→独立源码包装→SDF→实际视图/表情检查的完整链。

本轮已获得下述原生样例及实际引擎截图证据。CPU 单元测试和请求预检不能替代原生结果；原生样例通过也不等于最终审美、全组合兼容或完整角色产品验收。

## 导入性能与验收边界

历史截图会增加全新引擎导入负担。当前已将 20 个历史截图目录（1,332 张 PNG，共 2,684 文件）逐成员校验后归档为可恢复 ZIP，最近五版的 13 个证据目录和全部模型、脚本、GUT 测试保持原样。runtime/override.cfg 使用 PNG 无损导入；单独改变编码未能解决时限问题，配合历史截图整理后的原生导入和 GUT 才通过。
