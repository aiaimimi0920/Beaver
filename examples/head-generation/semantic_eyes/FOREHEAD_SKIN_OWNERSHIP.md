# Live authored shell ownership (capture prerequisite only)

The unique live `skin_detail` object with the explicit `Continuous facial shell`
group supplies actual face-region labels. Capture records its stable object name,
role/group and labels, and inspects **every other joined member** for collisions
or missing face-label authority. No native pointers, guessed region numbers,
proximity component, saved character face IDs or coordinates define membership.
The existing weld's independent legacy checks are unchanged.

The weld restoration report carries `authored_skin_ownership` (schema 1).
Missing/ambiguous evidence is unavailable, not inferred. A receipt falsely marked
validated despite collisions fails closed. The detached forehead stage resolves
source face IDs from the live native labels; raw and regularized author contexts
carry the same ownership while retaining their DISTINCT vertex arrays and the
explicit raw-to-author change proof. Ownership does not rebaseline geometry.

Consumer checkpoints expose availability and the resolved receipt. All native
labels and receipt values participate in the existing exact source binding;
changed labels or role provenance reject resume, including JSON round trips.
Native session pointers are not introduced. Missing old receipts retain legacy
consumer compatibility and no availability is fabricated; no new key is inserted
into legacy raw/author contexts merely to label missing evidence. An eventual
ownership-dependent support mode must require availability before running.

This does NOT enable automatic support, change default dispatch, assert connected
skin topology, or replace the exporter's separate skin scope. `native_ready` and
`full_model_success` remain false in this consumer slice. Future support still
needs connected-source coverage, actual witnesses, bounded transactions and all
unchanged quality/field/1 mm/posed/native/visual gates.
