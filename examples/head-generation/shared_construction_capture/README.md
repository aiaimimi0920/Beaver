# Opt-in construction identity capture

`construction_identity_capture="CONSTRUCTION_IDENTITY_CAPTURE_V1"` is an
explicit API option on the existing face-component, facial-surface and semantic
packagers. The default is `None`: existing generated geometry and runtime source
remain unchanged. The current insertion supports only the existing versioned
raw13 feature-flow recipe; other recipes fail before execution. The identity
journal and pure transport validators do not assume a row/column count.

This is **capture and lineage evidence**, not a geometry optimizer or a complete
facial-rail binder. It does not enable shared retile, assign diagnostic guide
colors to rows, freeze lower rows, infer correspondence from XYZ/UV proximity,
copy model point IDs, or authorize a shape/normal/UV/source-field change.

## Real production boundary

The optional adapter instruments the emitted, existing constructor at these
specific guarded sites, leaving the numeric helpers and their guards intact:

1. Initial dense chart allocation records row/column keys, actual source and
   mapped chart parameters, and the value originally appended at that site.
2. Sparse chin strips emit actual allocation ranges and their explicit sparse
   row station lists. Resampling an existing allocation does not invent a new ID.
3. Eye/mouth patch rings emit their actual ordered ring stations and open/closed
   interface semantics. Mouth symmetry endpoints and dense-chart column-zero
   stations explicitly declare mirror seam membership; coordinates do not infer it.
4. Outer row/fan reports supply actual point allocations, endpoint relations,
   parameters and ordered row rewrites. The replacement must preserve the exact
   original oriented patch boundary. Fan context is not a field-donor row.
5. Underside rows, side-strip fan stations and posterior-return parent mappings
   are captured at the actual allocation sites. Unreported allocations reject.
6. `compact_flow_vertices` supplies its actual remap. Every point value (including
   scalar type and signed zero), face cycle and live-point bijection is checked.
   Retired allocations remain in the history; identity is never a current index.

Faces receive identities at their first emitted checkpoint. Corners are bound to
that face and its original point occurrence, so rotating a face's storage cycle
cannot silently rebind a corner. Exact face histories and removed/new face IDs
are retained. Constructor roles broken by a feature patch or removed allocation
are reported as explicit fragments/breaks; no nearest station bridges the gap.
A surviving closed-path wrap edge remains in its ordered fragment.

Actual open-boundary edges are also enumerated exhaustively. Explicit aperture
paths and the half-mesh mirror seam are distinguished from unclassified open
boundaries. A nonzero radial coordinate does not authorize an outline point as
interior. Post-Mirror boundary incidence is recomputed using verified identities,
so a merged center edge is not falsely retained as an outline. These are fresh
constructor facts—not a reconstructed historical AUTHOR receipt, a complete
nose/ear exclusion map, or permission to activate a regularity operator.

The outer producer explicitly declares one complete ordered row group. Capture
verifies **every** actual cross-role edge in that group, rather than normalizing
individual strips independently, and derives every incident support quad for
its stations. This group covers those constructor rows only—not the missing
full semantic facial-rail handoffs. The support utility rejects unknown,
isolated, repeated, retired and nonquad-incident variables.

## Native identity phases

The constructor's actual half mesh is bound immediately at mesh creation.
Temporary typed INT attributes carry POINT/FACE/CORNER ordinals only during the
native operations being verified. Marker creation and cleanup compare all read
native attributes, topology, corner normals, editor flags, deform groups,
material slot names, UV selectors, color selectors and object frame.
No UV editor flag is written through deprecated loop setters.

Mirror correspondence uses exact oriented source corner/point cycles to identify
original versus reflected face occurrences. It requires both occurrences of
every original face/corner, two single-side vertices for each nonseam point, and
one shared vertex for each explicitly declared seam point. Undeclared merges,
stale stations, ambiguous/missing lineage and changed marker schema fail closed.
The mirror validator is pure; actual RNA propagation requires separately retained
native evidence, not these CPU tests.

Join assigns and verifies complete typed identity permutations for every actual
input component. Captured shell faces/corners keep explicit original-source and
mirror-side ancestry; unrelated components receive no construction-rail authority.
Duplicate instance identities reject. State is tied to the actual live object
and lifecycle, not its mutable name; renamed/replaced/consumed objects reject.
Cleanup is attempted for every live input even when field readback fails.
Join part `face_origins` and `corner_origins` are integer-native-index maps.
JSON readers must restore those schema-defined keys to exact integers before
recomputing the canonical source/join hashes; string-key ordering is not equivalent.

The opt-in weld boundary observes native `find_doubles` with the same ordered
vertex inputs as the retained original `remove_doubles` call. It requires pinned
Blender 4.3.2, exact surviving vertex objects and target coordinates, original
face-object donors, and a complete mapped oriented point/edge/face/corner
quotient. Duplicate face classes retain all candidates and the observed donor;
nonadjacent splits, missing incidence and ambiguous identity fail closed.
Edge custom-data donors are recorded separately from merged flag contributors.
No nearest-coordinate binding or surviving marker alone establishes lineage.

The EDGE marker is attached on Mesh before BMesh import and removed on Mesh
after export, with exact non-marker field checks. No BMesh CustomData layer is
allocated or removed inside the direct-object proof interval: such allocation
invalidates native Python pointers. Selection history uses the actual sequence's
indexed access, preserving order without relying on its non-reiterable iterator.

The original `dissolve_degenerate` call and distance remain unchanged. Full
identity/connectivity and every Python-exposed layer, geometry value, flag and
editor state must remain exact, except for an explicit identity-bound receipt
for the pinned operator's scratch `CORNER.tag` transition. Every existing loop
must end with tag `True`; all original and observed values are retained. This
is not a general flag ignore, model-field waiver, or admission of unexposed
CustomData. Any other change fails closed, including actual degenerate surgery.

**After this bounded weld/dissolve receipt, current-role admission is explicitly
invalidated before field restoration and subsequent surgery.** Posterior-return,
ear, nasal, chin and forehead surgery
currently lack complete constructor replacement/merge receipts. Earlier native
indices remain historical evidence only. `require_current_roles` always rejects;
no consumer is permitted to treat the historical constructor map as the current saved mesh.
Capture-only generation can continue only if its explicit native proofs pass,
but cannot acquire solver authority by doing so.

## Bounded oral donor verification

The optional path captures the actual ordered mouth half-ring handoff to the
real oral constructor. Every oral ring allocation is recorded; first-ring
stations retain explicit original/reflected skin parents and single seam
endpoints. Compaction, Mirror, actual join permutations and native weld groups
must compose exactly. Missing partners, extra contributors, duplicate owners or
any undeclared merge fail closed. Generic joined point indices or coordinate
matches cannot substitute for this producer relation.

Pre-join skin POINT fields, named group weights and shared-boundary crease fields
are frozen independently. The existing donor-restoration function still runs
unchanged, but its result must equal a complete identity-derived expected native
state. Only declared shared targets may receive those fields. Geometry, topology,
UV/corner data, oral-only values, unrelated attributes and editor state remain
exact. The legacy spatial lookup is not the acceptance authority and this is not
yet a replacement spatial-free writer. Original allocation, join and weld
receipt consistency is checked before transfer.

This bounded slice rejects other welds until independently receipted. Ear
membership, early geometry fairing, posterior return and later nasal/chin stages
remain unadmitted. The isolated compact and straight oral fixtures have each
verified 30 actual native skin/oral weld pairs, 30 identity-bound field donors
and 30 shared crease edges under Blender 4.3.2. Untouched and captured paths
matched across whole exposed native fields, including saved/reopened artifacts.
These nonzero-merge fixtures complement the earlier disjoint controls; they do
not establish complete generator, pose, GLB or visual acceptance.

## Packaging and independent boundaries

Runtime sources reuse the existing hash-verified source seed and retained
semantic bundle. Their exact implementation inventory is checked both when
retained and again before runtime bootstrap; a between-read source change or
changed/duplicate binding rejects. Output count, source-size and serialized-frame
limits are unchanged. A long output prefix can still exceed the frame guard;
callers must retain the existing seed plan and obey the actual measured limits.

The constructor option is independent of `POST_MORPH_SOURCE_CAPTURE_V1`; they can
be enabled together. The latter still captures the actual native source fields
and actual Basis plus six saved keys. Neither option silently fills missing
fields or reconstructs saved keys on the CPU.

Constructor allocation namespaces are **not** source-capture namespaces. Their
future connection requires an explicit typed identity mapping through every
native surgery. Immutable original RAW six fields, AUTHOR saved-key deltas,
stored deltas, admitted birth references and owner/UV/normal boundaries remain
independent authorities. The 0.5 mm birth and original 1 mm independent 11-pose
n32 gates are neither modified nor certified by this capture.

## Verification

```sh
PYTHONPATH=examples/head-generation/shared_construction_capture \
  python -m unittest discover -s examples/head-generation/shared_construction_capture/tests -v
```

Tests cover unrelated 3×4 and 5×7 layouts, exact replacement/compaction, actual
source packaging on two resolved compositions, complete incidence, shuffled
mirror storage, source corruption, lifecycle failures and retained-source hashes.
RNA stand-ins are not native acceptance. Full constructor execution depends on
real `mathutils`; do not replace it with a numeric approximation to pass tests.

An isolated Blender 4.3.2 fixture passed on two actual procedural configurations
(`research-compact-rounded` and `research-straight-tapered`). The unchanged default
and opt-in constructors produced exactly equal numeric arrays and native fields
at half-shell creation, after actual Mirror, and after a disjoint component join.
Each half had 479 points/424 quads; Mirror produced 925 points/848 quads and the
control-component join produced 929 points/849 quads. Typed identities, marker
cleanup and exact saved/reopened fields were verified. All numeric helpers and
guards used the original resolved source and native mathutils. Only the separate
oral-object creation side effect was intercepted equally, with its detached input
recorded; the actual shell mesh helper was retained and executed unchanged.

A separate isolated native weld fixture verified those two saved constructor
results against the exact original native operators and saved/reopened fields.
Both retained 929 points/849 faces with no weld targets; they do not alone prove
merging behavior. Native synthetic controls separately verified an external
point merge, adjacent-corner collapse and duplicate-face coalescence, with INT,
UV/pins, color, deform weights and editor flags. Nonadjacent splitting and actual
degenerate dissolve were rejected without changing their source Mesh. All
exposed data outside the explicit corner scratch-tag receipt remained equal.

Role admission remains false, and it does not connect constructor identities to the later six-key source
capture or certify anatomy support/source owners. No full generated-face, pose,
GLB, engine or visual acceptance is claimed here.
