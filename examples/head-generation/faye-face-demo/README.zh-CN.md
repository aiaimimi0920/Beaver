# 菲参考脸部组合与九视图示例

这是使用既有六部位框架生成的脸部初版，以《星际牛仔》菲·瓦伦汀为外观参考，不是官方模型、精确重建或外观验收完成的声明。
参考页面：https://www.cowboy-bebop.net/character/ 。选择与参数是风格解释，不是从图片测量得到的科学比例。当前眼型和整体成熟感仍需用户对照原作验收。

## 范围

- 只生成脸部；不制作头发、身体或完整封闭头骨。
- 复用 `face_components.bundle.build_plan`、原生源码封装及 SDF 流程。
- `selection.json` 选择杏仁眼、折角眉、紧凑鼻、唇带嘴、细长人耳和直线收窄下脸。
- `controls.json` 只使用已有的有界参数，不修改历史预设。
- 不包含原作图片、第三方模型或整个项目资源。示例依赖已经安装六部位运行时和 NPRCharacterFrame 的工程。

## 生成与捕获流程

1. 经 Beaver 规划与执行交接，用选择和参数构建一个全新组合目录的计划，保留整个计划。
2. 原生 `blender.start` 执行生成并轮询至成功，再用真实生成回执构建、执行源码封装请求。
3. 用生成及封装回执构建、执行 SDF 请求；验证实际输出身份。
4. 通过 Beaver 声明输出的工具安装 `faye_capture_probe.gd` 和 `faye_capture_schedule.json` 到 `showcase_extensions/`，安装场景到 `showcase/faye_face_capture.tscn`。Blender 写入脚本必须使用 `beaver_output(path)`，不能仅写相对当前目录后当作成功发布。
5. 先通过 `npr-character` 工作流验证新定义，再用配置好的 MiDot 引擎启动捕获场景，并将该定义的 `res://` 路径作为明确的用户参数。
6. 若展示台固定打开 `showcase/aster_head_review.tscn`，可通过有期望哈希的文件写入临时切换成同一捕获场景；关闭展示台后恢复原来的入口。独立捕获场景保留用于复现。
7. 检查生成清单的九张图片、源文件前后哈希、显示模式、相机、零嘴型/眨眼以及头发/身体隐藏状态。完成必要运行验证后交回结果。

## 九张图

顺序是 NPR、白模、真实三角边线；每组依次为正面、框架右侧 45°、右侧 90°。模型旋转分别为 0、-45、-90 度，俯仰为 0，统一正交尺度为基础尺度的 0.85。不在截图后镜像、绘制或生成替代模型图。

捕获程序在实际渲染帧之后保存 PNG。清单包含实际相机和网格可见状态、入口场景内容哈希，以及模型/定义/报告和运行脚本前后哈希。图片落在项目 `artifacts/faye_face/`；实际分辨率以清单记录的视口为准。
