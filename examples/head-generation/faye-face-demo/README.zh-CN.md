# 菲参考脸部组合与九视图示例

这是使用既有六部位框架生成的脸部初版，以《星际牛仔》菲·瓦伦汀为外观参考，不是官方模型、精确重建或外观验收完成的声明。
参考页面：https://www.cowboy-bebop.net/character/ 。选择与参数是风格解释，不是从图片测量得到的科学比例。当前眼型和整体成熟感仍需用户对照原作验收。

## 范围

- 只生成脸部；不制作头发、身体或完整封闭头骨。
- 复用 `face_components.bundle.build_plan`、原生源码封装及 SDF 流程。
- `selection.json` 选择杏仁眼、折角眉、紧凑鼻、唇带嘴、细长人耳和直线收窄下脸。
- `controls.json` 只使用已有的有界参数，不修改历史预设。
- 不包含原作图片、第三方模型或整个项目资源。示例依赖已经安装六部位运行时和 NPRCharacterFrame 的工程。

## 生成与捕获流程

1. 经 Beaver 规划与执行交接，用选择和参数构建一个全新组合目录的计划，保留整个计划。
2. 原生 `blender.start` 执行生成并轮询至成功，再用真实生成回执构建、执行源码封装请求。
3. 用生成及封装回执构建、执行 SDF 请求；验证实际输出身份。
4. 先确认工程已安装嘴部、脸部运行时；还需将 `../ear_library/ear_capture_view.gd` 安装到 `showcase_extensions/ear_capture_view.gd`，它是捕获器的直接预加载依赖，即使工程没有耳部截图工具也不能省略。然后通过 Beaver 声明输出的工具安装 `faye_capture_probe.gd` 和 `faye_capture_schedule.json` 到 `showcase_extensions/`，安装场景到 `showcase/faye_face_capture.tscn`。Blender 写入脚本必须使用 `beaver_output(path)`，不能仅写相对当前目录后当作成功发布。
5. 先通过 `npr-character` 工作流验证新定义，再用配置好的 MiDot 引擎启动捕获场景，并将该定义的 `res://` 路径作为明确的用户参数。捕获器要求实际渲染器为 Forward+，记录引擎报告的渲染方式与驱动；若引擎降级为 Compatibility 等其他渲染方式，则拒绝输出成功清单。
6. 若展示台固定打开 `showcase/aster_head_review.tscn`，可通过有期望哈希的文件写入临时切换成同一捕获场景；保留原入口内容，暂不恢复，先完成下一步的一致性检查。独立捕获场景保留用于复现。
7. 运行 `python verify_capture.py <工程根目录> <manifest.json 绝对路径> <检查输出目录>`，核验九张 PNG、源文件前后哈希、显示模式、相机、零嘴型/眨眼以及头发/身体隐藏状态；该检查器只依赖 Python 标准库，仍需人工逐张看图。检查通过后关闭展示台并恢复原入口；恢复入口会有意改变其哈希，不应再将它误认为捕获时的原始入口。将 `test_faye_capture.gd` 安装到工程 `tests/`，运行身份反例回归；完成必要运行验证后交回结果。

捕获器固定绑定本次已核验的组合身份与模型 SHA，并核对报告的 `new_glb_sha256`、实际加载的 SDF 贴图路径和前后哈希。材质绑定枚举全部导出的 Texture2D 属性，保留可选空值和别名，要求本例的 base、ILM、map、ramp、SDF 均存在，并在捕获后重新读取实际属性及文件哈希。独立检查器还要求完整嘴型通道、有限数值及三维相机向量，并读取清单中 `entry_scene_at_capture` 指向的实际工程内文件核对 SHA；不能只比较清单里互相相等的入口哈希。源码绑定覆盖 NPRCharacterFrame 与展示台运行时目录的全部可见文件及 `project.godot`，还记录并复核实际引擎二进制 SHA；不是只检查几个入口脚本。重新生成若产生不同模型字节，须先核验原生回执和选择/参数，再显式更新固定模型值；不能在捕获时自动接受任意当前文件。

## 九张图

顺序是 NPR、白模、真实三角边线；每组依次为正面、框架右侧 45°、右侧 90°。与继承的展示台“右45° / 右侧”按钮保持同一约定，模型旋转分别为 0、+45、+90 度，俯仰为 0，统一正交尺度为基础尺度的 0.85。不在截图后镜像、绘制或生成替代模型图。

捕获前要求模型、定义、生成报告和所有运行绑定都得到非空 SHA-256；捕获期间身份变化则不输出成功清单。捕获程序在实际渲染帧之后保存 PNG。清单包含实际相机和网格可见状态、入口场景内容哈希，以及模型/定义/报告和运行脚本前后哈希。图片落在项目 `artifacts/faye_face/`；实际分辨率以清单记录的视口为准。
