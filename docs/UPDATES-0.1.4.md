# Beaver 0.1.4：正式采用「一句成游」

2026-09-06，Windows x64 本地预览版。

## 已接入

- 采用用户选定的第四轮 A「一句成游」，原样保留绿色对话气泡、透明方向键和黄色按键。
- 统一左上角品牌位、页面 favicon、窗口图标、系统托盘与 Windows EXE 内嵌图标；删除临时字母 B 与旧托盘位图实现。
- 从一份 SVG 生成 8 个尺寸的 PNG 和多尺寸 ICO，构建自动更新，避免各入口各画一套。
- 保持已有 1120 × 760 窗口、186/52 px 侧栏、50 px 顶栏与统一右上角通知。不增加子标题或解释型 UI。

图形细节与维护规则见[正式图标规范](ui/BRANDING.md)。前四轮 HTML 候选稿与原始参考副本完整保留。

## 验证

- `npm run check`：类型检查、30 项自动测试和构建通过；其中新增 4 项品牌回归测试。
- 打包脚本重新解析生成的 EXE，校验全部内嵌图标帧与源 ICO 的 PNG 字节一致。
- 真实桌面验证脚本新增品牌 SVG 加载、28 px 尺寸、favicon 与 Windows EXE 图标提取检查；同时保留工具发现、侧栏、通知、任务、关闭到托盘及完整退出后恢复检查。
- **发布包的最终运行验证状态以该包 `RELEASE.json` 为准**：只有真实启动该 EXE、完成桌面验证并通过完整文件哈希校验后，才写入 `runtimeVerified: true` 和实际检查清单。测试截图与原始结果保存在仓库 `output/validation/desktop-*/`。

## 使用与边界

打开 `release/Beaver-0.1.4-win32-x64/Beaver.exe`，保留整个目录。若旧版仍在运行，请先自行从托盘退出旧版，再打开新版；本次不会自动关闭你的程序或覆盖旧包。

预览 EXE 未签名，仅验证 Windows x64。版本与品牌替换不改变用户数据位置、AI 配置、任务和游戏项目，也不表示已验证真实 AI 生成质量、macOS/Linux 打包或渠道发行。
