# 0.1.7 项目规划交互原型

本次按用户要求先做 UI 与含义，暂不实现新增规划对应的业务执行。完整说明见[项目规划交互契约](ui/PROJECT_BLUEPRINT.md)。

## 可以体验

- 三步创建：基本信息、创作方向、功能规划；仍支持接管已有项目。
- 64 主/副类别、49 预设主题和自定义主题、3 目标评级、4 游戏规模。
- 在线多人开关、架构、区域、每局人数、峰值 CCU、初期实例数。
- 项目设置中的设计、开发、后期：15 项独立 0–5 优先级，点击查看含义、未来交付和验收目标。
- 阶段任务预览；联系媒体、发布试玩版、广告宣传的渠道和约束草案。
- 本地规划保存、重新载入确认、草稿导航保留、revision 冲突保护、重启读取。
- 仍沿用 Loom 紧凑布局、左下角全局设置、固定侧栏图标和统一通知。

## 本版刻意不做

新规划不调用 Codex、不接入功能块、不生成故事或素材、不购买服务器、不发布试玩版、不发送邮件、不支付广告费用。选择功能规划不表示模块已安装。旧有真实任务、功能块接入、试玩与导出入口仍保留，用户可以明确进入这些入口执行。

新规划单独存在 Beaver SQLite，暂不写 `beaver.project.json`，也不随玩家程序导出。旧版 GameBrief 的任务上下文继续工作；不把新 UI 尚未确认的意思偷偷变成执行指令。

## 验证入口

```powershell
npm run format:check
npm run check
# 配置外部 Playwright 包位置后：
npm run verify:desktop
```

`tests/project-blueprint.test.ts` 验证目录、参数、已有项目保留、导入期间保存不丢失、revision 与游戏文件不变。真实 Electron 验收覆盖创建、15 项滑块、预览、三类发行草案、最小窗口和重启。实际结果和发布包路径见工作区 `output/validation/Beaver-0.1.7-summary.md`，不以此文档取代测试证据。

Windows 包为 `release/Beaver-0.1.7-win32-x64/Beaver.exe`，保留所有邻接文件；不覆盖旧版目录。先从托盘退出旧版再启动新包。当前仅对 Windows x64 进行本地包验证；其他系统、签名、云执行和自有集市仍未完成。
