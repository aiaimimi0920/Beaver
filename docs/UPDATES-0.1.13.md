# Beaver 0.1.13：创作看板

交付：`C:\Users\Public\nas_home\Beaver\release\Beaver-0.1.13-win32-x64-r2\Beaver.exe`

## 界面

创作页从列表加常驻详情改为 Trello 式卡片看板：

| 列 | 对应任务 |
| --- | --- |
| 待开始 | 等待执行 |
| 执行中 | 正在运行 |
| 需要你 | 等待补充、已中止、失败或合入冲突；卡片明确标出具体状态 |
| 待验收 | 已交付、尚未认可 |
| 已完成 | 已认可或已回退；回退卡片保留“已回退”标识 |

- 顶部只有搜索、方向筛选、数量和新任务入口。
- 卡片显示方向图标、方向色、任务标题、真实状态，以及必要的问题、冲突或文件数量。
- 需要回答的问题直接显示在卡片上；点击后进入完整问答。
- 点击卡片打开详情弹窗，对话、补充要求、工作副本、审查、认可、回退与变更记录继续使用真实业务。
- 新任务输入框按需展开，不再长期占据看板上半部分。
- 未打开项目时也显示空看板，通过“创建项目”开始，不显示虚构的执行卡片。
- 看板支持横向滚动，任务列内部滚动；不要求窄窗口强行压下五列。

## 方向标记

| 方向 | 图标 | 标记色 |
| --- | --- | --- |
| 综合 | 指南针 | 中性灰 |
| 剧情与设定 | 书本 | 淡紫 |
| 玩法与系统 | 拼图 | 浅蓝 |
| 美术与场景 | 调色板 | 灰粉 |
| 音乐与声音 | 音符 | 青灰 |
| 程序与技术 | 代码 | 蓝紫灰 |
| 测试与审查 | 盾牌 | 暖灰 |
| 构建与发行 | 播放 | 蓝灰 |

方向色仅用于小面积图标、文字和卡片顶边，不替代执行状态颜色；整体继续沿用深色 Neuro/Loom 壳层。

新建任务时可选择方向，已有卡片可在详情中修改。分类写入任务记录，重启后保留；执行结果保存和合入日志不会把刚修改的分类覆盖回旧值。

不根据提示词关键词擅自判定方向。旧的审查任务沿用“测试与审查”，其他未分类旧任务归为“综合”，用户可以手动整理。方向标签不改变 Codex 的执行权限或上下文选择流程。

## 明确边界

- 本轮实现卡片展示与分类，不提供拖拽修改执行状态。卡片必须随真实执行、回答、认可或回退移动，不能拖到“已完成”就伪造完成。
- 没有新增子任务编排、任务依赖或排期业务。
- 本轮没有重新验证真实模型的游戏创作质量、完整 Godot 导出或 Blender 流程。
