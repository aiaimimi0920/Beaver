# Beaver 0.1.1：界面精简与本机工具发现

日期：2026-09-06。范围仅为本轮 UI 优化和 Godot / Blender 检测修复，不代表商业平台或真实 AI 质量已经完成。

## 使用新版

Windows 程序：`release/Beaver-0.1.1-win32-x64/Beaver.exe`。

先从托盘退出旧版，再打开新版。保留 EXE 同目录的资源文件；原有用户数据目录不变，本轮没有修改数据库格式，也没有覆盖旧版发布目录。

打开“设置”即可自动检测工具。填写或选择其他路径后，“重新检测”会验证当前尚未保存的输入；点击“保存设置”后固定路径。

## UI 调整

- 删除页面口号、英文小标签、欢迎页理念卡片和重复二级标题。
- 导航改为任务、素材、功能块、设置；行高 36px，页面只保留一个短标题。
- 缩小顶栏、页头和控件间距，任务列表与详情改用连续面板。
- AI 能力、本机工具、执行扩展改为平级折叠设置，保留未保存草稿。
- 素材审阅和任务输入保留直接操作，不再常驻解释段落；预览支持键盘，读取失败有独立错误状态。
- 错误、冲突、权限与回退风险提示没有为了视觉精简而删掉。

后续 UI 必须遵守 [紧凑界面约束](ui/COMPACT_UI.md)，不能重新退回解释型界面。

## 漏检原因与修复

修复前现场调用 `findTool("godot")` 和 `findTool("blender")` 均返回未检测到，但实际程序执行 `--version` 成功。

- Blender 实际位于 Steam 库，而旧实现只扫描 Blender Foundation 的标准目录。
- Godot 是便携式安装，既不在当前 PATH，也没有 GODOT_PATH；旧实现只补充了 Scoop 与 WinGet Links。
- PATH 中的版本化 Godot 名称与简单 `.cmd/.bat` 启动器也未覆盖。

现增加 Windows App Paths、卸载注册信息（包括 Steam 的安装位置）、文件关联、开始菜单/桌面快捷方式及系统记录的便携程序路径。只查询相关应用线索，不扫描整盘，不读取个人 Codex 配置或认证文件。

路径仍需真实存在。Godot 自动发现排除导出模板、headless/server 程序，并优先将 console 路径解析到同目录图形编辑器；显式选择已知导出模板也会报错。简单启动器只解析目标，不执行其中任意 shell 脚本。用户手动指定的重命名编辑器仍保留支持。

本机存在多个 Godot。当前无配置的实际检出结果是 **Godot 4.0.2 stable** 和 **Blender 5.2.1 LTS（Steam）**；这表示找到了可运行安装，不表示自动选取最新版本。需要其他已有 Godot 时可在设置中固定对应 EXE，应用不自动升级或切换引擎。已用自动检出的 Godot 通过 Beaver 启动起步游戏并验证其可见窗口。

## 已验证

- `npm run check`：TypeScript、24/24 自动测试、构建通过。
- 新增回归覆盖：带空格的 Steam 安装根目录、便携安装、过期路径、导出模板排除、console 到 GUI、简单启动器和显式配置路径。
- `npm run verify:desktop`：真实 Electron、真实 IPC，无 API 后端替身；清空 Godot/Blender 配置和环境覆盖后两者自动检出，设置实际显示版本和路径。
- 桌面测试还覆盖未保存路径报错/恢复、折叠草稿、弹窗焦点与 Escape、键盘素材预览、读取错误、图片框选、模型/音频、试玩以及退出后恢复。
- 960 × 680 是当前实际最小窗口，任务与素材页均检查无横向溢出并截图。
- `npm run verify:codex`：真实 Codex 进程与固定 Responses 应答的并发、补充、中止、续跑回归通过；不是实际模型质量验收。

源运行证据：`output/validation/desktop-1788638864127/` 与 `output/validation/codex-1788638892546/`。各桌面运行的 `desktop-proof.json` 保存实际 EXE、检出路径、版本、布局指标和检查清单。

发布包另行运行同一桌面脚本并逐文件校验；结果以该包 `RELEASE.json` 的 `runtimeVerified` 和 `runtimeChecks` 为准，未通过前不标为 true。

## 边界

Windows 发现策略不保证找到从未启动、从未注册、没有快捷方式且不在 PATH 的任意文件夹中的便携软件；这种情况下使用“选择”。无法访问的安装位置不视为可用程序。没有把个人 Z: 路径硬编码到产品。

本轮没有安装或升级 Godot/Blender、修改个人 Codex 配置、改动 Neuro/Loom 来源，也没有扩展集市、计费后台或跨平台打包范围。
