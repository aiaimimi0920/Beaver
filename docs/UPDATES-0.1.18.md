# Beaver 0.1.18 - 本机工具准备

日期：2026-09-07。交付版本：`release/Beaver-0.1.18-win32-x64-r3`。

本轮完成基础工具准备闭环，并将其从长设置页中独立出来；不是整个产品目标已经完成。

## 使用入口

运行发布目录中的 `Beaver.exe`，点击左下角「创作环境」，点击「一键准备工具」。请保留完整发布目录，不要只复制 exe。

- 检测 Node、Codex、Godot、Blender 的实际可执行文件及版本。
- 已安装且版本验证通过的工具直接复用；缺失工具按依赖顺序安装，Node 先于 Codex。
- 安装程序退出后再次检测，只有真实可用才保存路径，不将安装退出码当作就绪证明。
- 支持停止准备；失败后停止后续步骤，再次准备会复用已经就绪的工具。
- 准备状态落盘。应用完全退出后的未完成准备标记为已停止，下次打开不会擅自继续安装。
- 准备期间禁止保存或导入设置，防止旧设置覆盖刚验证的路径；失败或停止后也刷新已完成步骤。
- Codex 管理安装识别 hoisted、nested 与 legacy vendor 布局，不覆盖用户自己的 Codex 配置。
- 创作环境独立展示四个工具；设置页仍保留 AI 服务配置。常规窗口和 980 × 680 窗口下，正常就绪界面无需滚动。

## 尚未完成的产品目标

1. 干净 Windows 机器上从零安装全流程，包括权限提示、网络失败、安装源不可用和重启后的 PATH 发现。
2. Godot 导出模板与项目引擎版本的兼容性准备；基础工具版本检查不代表任意已有项目兼容。
3. Blender add-on、MCP 服务连接及预置插件的自动准备和端到端检查。当前工具「就绪」仅表示可执行文件版本检查通过。
4. 用户真实 AI 服务驱动的完整原创游戏制作、人工迭代与最终游玩验收。
5. 全应用所有页面和极端错误内容下的无滚动布局验收；本轮明确验证的是创作环境正常状态及交互回归覆盖的页面。
6. 平台额度后端、后续云执行、集市与渠道发行仍不在本轮交付中。
