# Electron → Tauri / Rust 迁移进度

目标：完成技术栈更换，保留现有产品能力，以完整未压缩 Beaver 发布载荷不超过 50 MB 验收。当前尚未完成，旧 Electron 发布包不是迁移交付物。

## 迁移边界

- React 界面、任务及项目语义保留。
- Node 主进程能力迁往 Rust，不将 Electron 或 Node 另藏为运行时后台。
- 开发阶段的 TypeScript 构建和测试仍可使用 Node，不能混同为最终部署依赖。
- Codex、Godot、Blender 是外部创作工具，单独准备并报告成本。
- 不改动 Loom/Hook；不修改或自动转换用户现有数据。
- 旧发布版本作为功能对照与回退入口保留。迁移完成前，不让新旧程序同时写同一数据目录。

## 已落地：Rust 数据核心

新增 Cargo 工作区与 `native/core`，使用 Rust + bundled SQLite 实现原 Store 的实体读写、顺序、事件分页、事务与任务恢复语义。

兼容原始 `entities`、`events` 表及 JSON 数据形状，不添加破坏性迁移；未知字段和不透明密文原样保留。密文原样保留不代表已经实现跨宿主解密，凭据迁移仍是待完成项。

任务恢复必须在文件日志恢复与应用独占之后调用；本轮没有绕过这两个前置条件去接管用户数据。
