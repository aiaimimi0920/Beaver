# Beaver 0.1.3：统一通知与图标候选

日期：2026-09-06。仅修改 Beaver；未改动 Loom、个人 Codex 配置或项目数据格式。旧版本发布目录保留。

## 统一右上角通知

参考 Loom `apps/desktop/src/components/feedback/AppFeedback.tsx` 与 `src/styles/workspace.css` 的通知入口、Portal、右上定位与信号色：

- 全局操作结果、启动刷新错误、窗口控制错误统一使用 `NotificationProvider`；不再使用挤动页面的 `.banner`。
- 顶部 64px、右侧 18px、宽 420px，窄窗口收缩；每条最小高度 64px，间隔 8px。位于 50px 窗口控制栏下方。
- 成功 / 信息 3.2 秒自动关闭，警告 4.2 秒；悬浮或键盘焦点停留期间暂停，离开后重新计时。重复内容合并计数，不反复堆叠。
- 与 Loom 有意不同：操作错误保留到手动关闭，避免没有其他记录的错误自动丢失；长文本可滚动、可选择复制，不套用固定高度裁切。多条通知按实际高度排列，整栈限制在窗口内。
- 创建项目、导出、安装和回退确认仍使用原有对话框。任务错误、合入冲突、素材读取失败、工具路径校验仍在对应位置持续显示。
