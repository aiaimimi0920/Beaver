# Beaver 0.1.19 - 导出模板准备

日期：2026-09-07。上一目标轮有进展：完成 0.1.18 基础工具准备并通过打包应用验证。本轮继续补齐无需打开 Godot 编辑器的游戏交付路径；完整产品目标仍未完成。

## 新增功能

游戏 → 导出游戏，提供「下载 Windows 模板」「导入模板包」和准备期间的停止按钮。

- 读取实际 Godot `--version`，不从安装目录名称推断版本。
- 官方标准稳定版可以下载对应 TPZ；下载使用流式写入、20 分钟超时、2 GiB 上限，并对照官方发布的 SHA-512 清单验证，失败不安装。
- 可导入用户选择的可信本地 TPZ，检查包内版本是否匹配。此路径不宣称验证了包的来源真实性。
- 本轮安装 Windows x86_64 release/debug 模板；不把其他架构、平台和 .NET 支持混同为已完成。
- 遵循 Godot 普通数据目录和 `_sc_` / `._sc_` 自包含目录规则。
- 只提取明确允许的文件名，先在独立暂存目录检查，再发布；拒绝覆盖已有目录。已有可用模板直接复用，已有不完整目录保留并报告。
- 停止及托盘退出会取消本次准备；清理仅限本次创建的下载与解包暂存目录，不改用户的原始模板包。

模板目录规则参考 [Godot 官方数据路径文档](https://docs.godotengine.org/en/stable/tutorials/io/data_paths.html)；TPZ 格式参考 [Godot 官方导出文档](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_projects.html)。下载与校验清单来自匹配版本的 [Godot 官方构建发布](https://github.com/godotengine/godot-builds/releases/tag/4.6-stable)。

## 尚未证明的事项

本轮真实模板包为本地已有文件，没有重新执行 1 GB 以上的官方网络下载；自动下载协议已有实现和测试，但网络限速、完整下载、断网与供应商故障仍需实机验证。文件大小和 MZ 头检查只证明基本结构，不能替代实际游戏运行或包来源验证。

自定义引擎的同名版本不保证 ABI 完全兼容；本轮的自定义 4.6 引擎与所导入模板已经通过实际导出测试，不推广为任意自定义引擎的兼容保证。

可运行产物是现有原创起步模板的真实构建，不是新近由真实付费模型独立制作的完整游戏。画面、音乐与玩法质量仍需用户认可。任务会话交互回归仍使用真实 Codex 进程与固定响应服务。
