# Beaver 0.1.14：单屏创作与任务会话

交付程序：`C:\Users\Public\nas_home\Beaver\release\Beaver-0.1.14-win32-x64-r2\Beaver.exe`

## 本轮调整

### 单屏看板

- 五列自适应可用宽度，不再设置导致横向滚动的列最小宽度。
- 根据实际窗口高度计算每列容纳的卡片数量；更多任务通过列底部翻页访问，不再纵向滚动。
- 搜索与方向筛选继续作用于全部任务，而不是仅当前页。
- 新任务使用独立单屏表单，不再挤占看板高度。
- 卡片仍是摘要；完整目标、问题和文件信息在任务会话中读取。没有靠全局隐藏滚动条来掩盖任务内容溢出。

这里的“单屏”是当前视图、操作区和分页控制都落在屏幕内；大量任务和长文档通过翻页访问，不是把任意数量的内容缩小后同时塞进一个画面。

### 更直接的补充对话

点击卡片进入独立任务会话，不再弹出叠加详情窗口。

- 顶部固定当前任务名称、状态与方向；“看板”随时返回。
- 中部使用“对话 / 文件 / 要求 / 执行记录”切换内容，长记录分页阅读。
- 底部固定多行输入区，输入过长时分页编辑，保留全部文字；输入草稿按任务缓存，返回看板后仍可继续。
- 连续的 Codex 流式片段组合为一条消息，不再给每个片段重复加角色标签；已展示的最终汇报不再追加一遍。
- AI 一次提出多个问题时，逐题切换并填写，全部回答后一次提交。不会用默认选项代替用户回答。

| 当前任务状态 | 输入区操作 |
| --- | --- |
| 执行中 | 发送补充到当前 Codex 执行轮次 |
| 等待执行 | 保存补充，开始时使用更新后的要求 |
| 已中止 / 失败 | 补充并继续，也可以直接点击“继续任务” |
| 等待回答 | 回答当前问题，完整提交后继续 |
| 已交付 / 已回退 | 继续创作，建立关联后续任务 |
| 合入冲突 | 根据补充要求创建整合任务，不覆盖原项目 |

已交付任务不再出现“没有输入入口，只能自行回去新建任务”的断点。后续任务保留独立快照和回退记录，记录 `parentTaskId`，可返回原任务；原目标、汇报、参考和已确认回答写入新工作副本的 `.beaver-context/followup/task.json`，供 Codex 选择和读取相关上下文。

标准回退放在文件视图中：分页勾选需要保留的文件，然后确认回退。对话型回退继续通过输入区的操作选择发起。
