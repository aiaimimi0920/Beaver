# 0.1.11：创作工作区交互预览

本版把已确认的 HTML 布局实现为 Beaver 的 React / Electron 界面，继续以确认交互为目标，未增加新的任务执行、自动合并或文件写入业务。

## 体验入口

打开应用即可体验，不需要先安装 Godot、Blender 或配置 AI。

- **创作**：仅输入目标发起预览任务；中止、补充、继续、整合、验收、回退。初始任务包含脚本冲突与立绘版本取舍两个情境。
- **资料**：文件树、多标签、Markdown 阅读和人工编辑、大纲与反向链接、当前文档的 AI 修改入口。使用“版本冲突”查看并行编辑时的对比与保留副本交互。
- **素材**：文件夹、搜索、类型筛选、缩略图大小、多选、属性和备注；双击或空格预览；支持生成、参考生成、AI 修改与统一风格的任务入口。
- **游戏**：已有项目的总览、创作重点和功能包收在同一入口中。
- **创作环境 / 设置**：始终放在主侧栏底部，收起侧栏不改变图标位置。

“预览下一步”只切换示例状态，不表示 Codex 完成了任务或验证。需要取舍的任务暂停再继续，仍返回取舍页面，不能绕过决定。

## 数据边界

新页面顶部明确标记“交互预览”。其中的文档、素材和任务均为示例，不是当前项目文件；预览草稿保存在本机界面存储中，关闭重开仍保留，可以“重置预览”。不同项目的预览草稿分别存储。

“已有任务”和“项目文件”保留原有真实功能入口。游戏设定、项目创建、工具安装和设置页也是原有真实功能，并未改成模拟；本版不把它们的执行结果与预览任务混合。

没有实现自动冲突解决、真实三方合并、强制执行隔离、AI 生成、文档文件保存或新的任务回退机制。未把前一轮 HTML 原型覆盖或删除。

## 验证说明

采用独立应用数据目录验证实际 Windows 桌面包，未使用个人 API 配置或真实游戏项目。类型检查、单元测试、格式检查与桌面交互记录保存在仓库 `output/playwright/studio-ui/`；发布包完整性由 `scripts/verify-release.mjs` 校验。

这是未签名的 UI 预览包，不代表完整生产执行链已经重新验收。
