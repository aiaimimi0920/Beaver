# 0.1.10 总览卡牌布局与二级选择

- 删除总览旧表格与重复页标题。左上只显示游戏名字，右上独立设定卡，左侧剩余区域暂时留白。
- 类别、主题以图标和主值展示，评级、大小、联机、风格集中在同一张卡内；保留 Beaver / Loom 深色风格。
- 解锁后点击齿轮打开二级选择。类别支持主/副槽位，主题支持预设和自定义，评级/大小/风格以卡片单选。
- 长目录支持搜索、排序、选中标识与内部滚动；底部操作固定可见。不复制参考游戏的商业美术或解锁/提示数机制。
- 弹窗“应用”只更新草稿；取消或 Escape 不改变之前选择。总览“保存设定”仍会重新锁定并显示强风险提示。
- 在线多人容量改为独立设置弹窗，原字段和校验保留。

仍是 UI-first：不修改 Godot 文件，不自动调用 AI，不部署服务器。创建向导保留原表单。完整控件含义见[总览交互契约](ui/PROJECT_OVERVIEW.md)。

Windows 预览包：`release/Beaver-0.1.10-win32-x64/Beaver.exe`。先托盘退出旧版再启动，保留整个发布目录。未签名，旧版发布不覆盖，未修改个人 API 配置。

实际构建与桌面验收结果见 `output/validation/Beaver-0.1.10-summary.md`。
