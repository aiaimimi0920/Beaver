# Beaver 0.1.2：按 Loom 实际布局对齐

日期：2026-09-06。范围是桌面 UI 壳层与密度优化，没有修改 Neuro / Loom，也没有更改任务执行、项目数据格式或个人 Codex 配置。

## 启动

`release/Beaver-0.1.2-win32-x64/Beaver.exe`。请先从托盘退出旧版，再启动新版；关闭旧窗口并不等于退出。保留整个发布目录，不能只复制 EXE。预览包未签名，0.1.0 / 0.1.1 发布目录保留。

## 本次对齐

| 项目 | 当前实现 | Loom 实际来源 |
| --- | --- | --- |
| 默认内容区 | 1120 × 760 逻辑像素 | `apps/desktop/src-tauri/tauri.conf.json` |
| 侧栏 | 展开 186px，折叠 52px | `apps/desktop/src/styles/shell.css` |
| 标题栏 | 50px，无系统重复标题栏 | 同上，`App.tsx` |
| 左上 | 折叠按钮 36px、品牌标记 28px、产品名 | 同上 |
| 导航 | 行高 36px，间隔 5px | 同上 |
| 左下 | 设置固定在底部，距底边 9px | 同上 `rail-footer` |
| 右上 | 刷新、最小化、最大化 / 还原、关闭；窗口按钮宽 48px | 同上 `window-control` |
| 工作区 | 页头 86px，内容边距 22px / 26px | `apps/desktop/src/styles/workspace.css` |
| 设置 | 单一标题、同一行服务来源切换、66px 平级折叠行 | `apps/desktop/src/styles/settings-shell.css` |

保留 Beaver 品牌和业务，不复制 Loom 的设备、MCP 商店等无关入口。Beaver 最小窗口仍为 960 × 680；Loom 当前配置没有规定最小值。Windows 150% 缩放下观察到创建无边框窗口时内容高度多出 2px，已在创建后校正内容尺寸；系统外框可能仍有物理像素取整差异，不以外框冒充内容区尺寸。

## 删除与压缩

- 删除重复项目名称、顶栏 AI 来源文字、底部空闲状态及常驻版本号；项目选择只显示一次。
- 新建项目和打开项目改为顶栏图标按钮，保留名称、悬浮提示和键盘访问。
- 设置从上方主导航移到所有页面共用的左下角；设置页左上返回原工作区。
- 任务输入保留文本区；提示词、执行选项、发出任务合并一行，默认输入面板不超过 160px。执行选项按需展开且保留输入。
- 无任务时只显示一处空态，不再同时显示“全部 0”“暂无任务”“选择任务”。
- 设置不再套用工作区页头，也不在每个服务右边重复显示“未配置”。默认折叠，按需打开；保存按钮在滚动时保持可用。
- 保留错误、安装权限、工具实际版本、回退风险和云端后台未实现的说明，未为了精简伪造成功或隐藏故障。

## 验证与边界

桌面验证使用真实 Electron 和真实 IPC；新增检查窗口命令白名单、不同发送者隔离、最大化 / 还原 / 最小化、关闭到托盘、展开 / 折叠尺寸、设置返回原页、任务草稿和选项保留。任务、素材、设置均检查最小窗口下无横向溢出；设置还检查保存按钮和底部入口可见。

本次继续回归无覆盖路径时的 Godot / Blender 自动检出、素材图片框选、音频、模型、工具路径校验、真实 Godot 试玩、重启后任务保留。没有安装或升级用户工具，没有调用真实付费模型；不把 UI 或协议验证当作完整游戏生成质量证明。

发布验证以对应目录 `RELEASE.json` 的 `runtimeVerified` 和逐文件校验为准；其中保存实际发布 EXE 的运行证据路径，不用开发模式的通过结果替代发布包验收。
