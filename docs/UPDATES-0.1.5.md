# Beaver 0.1.5：侧栏图标固定位置

2026-09-06，Windows x64 本地预览版。

## 问题与修复

真实运行 0.1.4 复现：收缩侧栏时，左上角折叠按钮图标向左移动 6 CSS px，任务、素材、功能块与底部设置图标向左移动约 2 CSS px。原因是展开与收缩规则分别定义了不同的左侧内边距，并非图标资源本身的问题。

参考 Loom `apps/desktop/src/styles/shell.css` 的固定图标列和共用导航行结构，但不照搬其两态不同的 padding：

- 品牌区两态统一使用 `padding: 0 8px`。
- 导航及底部设置按钮两态统一使用 `padding: 3px`，保留 28 px 图标单元格。
- 删除收缩态重复的 padding 覆盖，收缩只改变列宽、标签显示和间距。
- 保留 186/52 px 侧栏宽度、50 px 顶栏、36 px 行高、底部设置位置、正式图标和任务行为。

只修改 Beaver；没有修改 Loom 或上游 UI 参考副本。

## 回归验证

`scripts/desktop-smoke.mjs` 新增真实 SVG 边界坐标比较，覆盖折叠按钮及四个导航图标：

1. 默认窗口的展开、收缩、再次展开，逐项严格比较 x、y、宽度和高度。
2. 收缩态进入设置页，图标位置仍不变化。
3. 最小窗口 960 × 680 的展开、收缩及恢复。
4. 继续执行草稿保留、通知、工具发现、窗口控制和完整退出恢复等原有桌面回归。

修复前新增坐标断言在 0.1.4 发布包上失败；修复后源码真实 Electron 桌面回归通过。每次运行输出 `rail-anchors.json` 和展开/收缩截图，发布包最终验证状态见其 `RELEASE.json` 的 `runtimeVerified` 与 `runtimeChecks`。

## 使用

打开 `release/Beaver-0.1.5-win32-x64/Beaver.exe`。如旧版仍在运行，请先自行从托盘退出旧版，并保留新版整个目录。旧发布包不覆盖，预览程序仍未签名。
