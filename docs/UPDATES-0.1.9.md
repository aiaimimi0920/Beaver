# 0.1.9 游戏总览与编辑保护

- 左侧新增“总览”，显示游戏名称、主副类别、主题、评级、大小、在线多人及表现风格。
- 默认锁定；主动开启“编辑设定”才能修改，保存后重新锁定。
- 保存后的风险弹窗不自动消失，明确显示变更字段和游戏不兼容风险，需要手动关闭。
- 关闭编辑时确认是否放弃；跨页面保留草稿，返回默认锁定，重启保留已保存值。
- “项目设置”不再提供基础字段的无锁编辑入口；后端也拒绝通过普通规划保存改变基础设定。
- 沿用 Loom 深色紧凑布局和侧栏固定图标，不照搬参考图的蓝白主题。

仍是 UI-first：只保存 Beaver 本地元数据，不重构 Godot 游戏、不修改游戏目录或启动 AI。修改游戏名称只改变 Beaver 显示名。完整语义见[总览契约](ui/PROJECT_OVERVIEW.md)。

Windows 包：`release/Beaver-0.1.9-win32-x64/Beaver.exe`。请先从托盘退出旧版再打开新版，保留整个发布目录；旧发布不覆盖，新包未签名。未修改个人 API 配置。

编译、测试、真实桌面回归、发布清单和截图证据见 `output/validation/Beaver-0.1.9-summary.md`。
