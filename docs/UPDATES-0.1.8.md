# 0.1.8 引擎能力功能包规划

新增 City Game Studio 引擎技术字段对应的 **68 个功能包规划项**，与已有 **10 个附带源码的包**合计 78 项可选。完整分类、全部来源键与语义见[引擎能力功能包目录](ui/ENGINE_PACKAGES.md)。

## 可以体验

- 功能块工作区默认进入“功能包规划”，另设“源码包”页保留真实接入。
- 创建和项目设置中的功能选择同步扩展，已有项目可随时调整规划。
- 名称 / 用途 / 来源键搜索、分组和来源筛选、仅已选、全选当前、清空、逐项说明。
- 两个工作区共用项目草稿与保存流程，保存后重启保留。
- 新能力标明仅规划，不提供虚假安装、版本和成功状态；真实任务入口也会拒绝接入它们。

## 边界

本轮仍是 UI-first：不实现 68 项实际引擎功能，不生成代码，不部署服务器，不接入广告或支付。原有 10 个源码包、任务、试玩和导出能力保持原语义。没有变动 `.gd` 文件或更换用户工具 / API 配置。

包路径：`release/Beaver-0.1.8-win32-x64/Beaver.exe`。先从托盘退出旧版再启动；保留整个目录。旧 release 不覆盖，预览包未签名。

专项用例在 `tests/engine-packages.test.ts`，真实交互验收在 `scripts/packages-smoke.mjs` 与原完整桌面回归内执行。实际结果和截图以工作区 `output/validation/Beaver-0.1.8-summary.md` 为准。
