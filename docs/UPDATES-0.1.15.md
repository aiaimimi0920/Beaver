## 交付

- Windows 程序：`release/Beaver-0.1.15-win32-x64/Beaver.exe`。
- 保留此前所有发布目录，没有覆盖旧版本。

## 本轮交互

### 需要你处理的任务

任务卡片和会话标题显示黄色、带感叹号的明确标记，不只依靠颜色区分：

| 状态 | 标记 |
| --- | --- |
| 等待回答 | 待回答 |
| 合入冲突 | 待整合 |
| 执行失败 | 待处理 |
| 已中止 | 待继续 |
| 已交付但未认可 | 待验收 |

执行中的卡片及会话状态显示轻量移动线条。系统开启减少动态效果时，线条改为静态；排队、结束和中止后不再显示执行动画。

### 任务内的资料与素材

进入任务，点击「资料与素材」：

- 列出显式参考文件、已记录修改，以及刷新时检测到的工作副本新增、修改、删除文件。
- 图片可预览、音频可播放，GLB / glTF / OBJ 使用已有 3D 查看器；文本分页阅读。
- 预览明确使用任务工作副本，而不是把项目中的其他版本冒充这个任务的产物。
- 「针对文件反馈」把文件路径带入当前会话；若任务正在等待回答，则带入当前问题的回答草稿，不创建另一个无关会话。
- Markdown 可点击「编辑项目文档」，读取项目当前版本后人工修正。保存沿用版本冲突检查及独立回退记录，不直接覆盖 AI 正在写入的工作副本。
- 文档草稿可跨页恢复。保存成功后，文件及修正说明带回会话，由用户补充意见并提交。

### 委派子任务

进入「子任务」，输入目标并点击「委派子任务」：

- 创建真实的新任务，保留父任务 ID 和关系类型。
- 保存父会话目标、汇报、参考、提问及对话记录，供子任务自行选择上下文。
- 新任务拥有独立工作副本、执行状态和修改记录，复用现有合入冲突检查与回退机制。
- 子任务从项目已合入版本开始，不偷偷复制父任务尚未交付的修改；提示词明确要求缺少前置成果时询问用户。
- 可以从新会话返回原任务，也可从原任务查看关联任务。父任务等待回答时仍可委派，不会因子任务结束而被自动回答或标记完成。

任务会话仍保留补充、中止、继续、要求、执行记录、文件差异、标准回退和对话回退入口。

## 明确边界

- 相关文件列表不是 Codex 全部内部阅读行为的审计记录。尚未宣称捕获所有被 AI 自行阅读的上下文；执行中新增文件需点击刷新发现。
- 当前内置人工修改限于项目已有 Markdown。图片、音频、模型可审阅并反馈给任务，但没有内置绘图、音频剪辑或建模编辑器；`.blend` 等不支持的格式通过工作副本及对应工具处理。
- 子任务是关联的独立会话，不是 Codex 内部线程的无损 fork，也没有增加自动等待依赖、自动汇总子任务或自动完成父任务的调度器。
- 已完成任务的后续创作同样保留关联关系，可在原任务的关联列表中进入。
- 测试使用实际安装的 Codex 和本机模型协议夹具，不使用用户密钥，也不把夹具返回当成真实模型创作成果。
- 未进行完整 Godot / Blender 游戏生成及运行验收；发布清单继续保留 `runtimeVerified: false`。
- 本轮无滚动验证覆盖创作看板及任务会话，不代表资料、素材、设置等其他页面已经全部改造。
