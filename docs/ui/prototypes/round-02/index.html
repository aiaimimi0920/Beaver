这轮确认入口、分区和内容，不确认视觉细节

入口 放什么 不放什么
创作 人发出的任务、结果、对话、反馈、变更和任务回退。选择任务后，在同一主区切换结果与对话。 不展示默认展开的 Codex 内部计划、节点或工种编排。
资料 文件树、文档标签页、Markdown 阅读与编辑、大纲与反向链接；AI 修改围绕当前文档发起。 不是一组“AI 员工”，也不要求用户给每次任务挑选上下文。
素材 文件夹、筛选、缩略图、属性；支持预览、多选、AI 修改、参考生成与统一风格。 不把功能代码与世界观文档混进图片瀑布流。
游戏 总览与锁定的基础设定、三个阶段的创作重点、功能包、试玩、可运行程序导出和版本记录。 不放应用 API Key 或工具安装配置。
左下角 创作环境、AI 服务、后台运行与回退设置。首次使用单独引导自动准备环境。 不把 skills、MCP 和向量数据库当作普通用户的一级创作入口。

贯穿所有页面的动作

对资料、素材或游戏提出修改 → 带上用户选中的对象，进入新的创作任务。Codex 自己决定还需要搜索和读取哪些资料。

“待验收”只表示结果等待人看，不代表 Codex 每一步都要审批。执行与认可分开。

旧入口去向

任务 → 创作；总览 → 游戏 / 总览；功能块 → 游戏 / 功能；项目设置 → 游戏 / 创作重点；素材保留；新增资料。

游戏模板只在创建时选择；接管项目不覆盖模板。功能包后期可添加和更新。

暂不进入首版导航

自有游戏 / 素材集市、支付奖励、外部渠道发行和云端执行。平台额度与自配 API 是服务来源，首版执行位置仍在本机。

全部交互仅为本页演示，刷新还原。支持切换页面、示例筛选、文档编辑、设定锁和弹窗；不会调用真实工具。
