# Beaver 布局草案 02

入口：[index.html](./index.html)。直接用浏览器打开，无需启动 Beaver。

这轮只确认入口、分区与操作位置。所有数据都是示例，修改只保留在当前页面内；刷新会重置。不会读取项目、调用 AI、安装环境或导出游戏。正式应用与第一版原型保持不变。

## 布局

| 页面 | 左侧                                       | 中间                                   | 右侧 / 操作                                   |
| ---- | ------------------------------------------ | -------------------------------------- | --------------------------------------------- |
| 创作 | 用户发起的任务                             | 结果、对话、变更与回退                 | 下方输入补充要求；参考与执行限制可选          |
| 资料 | 按内容归档的文件树、搜索、新建文档         | 多文档标签、阅读 / Markdown 原文编辑   | 大纲、反向链接，或当前文档的 AI 修改          |
| 素材 | 文件夹、收藏、未分类                       | 搜索、类型、排序、缩略图大小、素材网格 | 属性、备注、AI 修改、参考生成；多选后统一风格 |
| 游戏 | 沿用上一轮的项目设定、阶段重点与功能包入口 | 游戏信息卡与试玩位置                   | 锁定编辑、风险确认、导出入口                  |

环境与设置保持在主侧栏底部。应用外的草案工具条用于切换首次使用流程与查看布局说明，不是正式产品顶栏。

## 这轮可以实际点击什么

- **资料**：打开或关闭标签；人工编辑、保存、Ctrl/Cmd+S；切换文档仍保留未保存草稿；通过双向链接跳转；新建空文档；针对当前文档提交 AI 修改要求。存在草稿时先确认保存，再创建模拟任务。
- **素材**：按文件夹、名称、标签或类型筛选；切换排序和缩略图大小；复选框或 Ctrl/Cmd 多选；双击或空格预览；修改显示名称和备注；收藏；打开生成、参考生成、AI 修改、统一风格的任务入口。
- **生成**：选择类型、数量、提示词模板和归档文件夹；创建模拟任务后留在素材库。不会插入假装已经生成的素材。
- **创作**：新任务只要求一个目标，不要求选取上下文；模拟任务支持中止、继续、补充要求和查看结果。资料或素材中的 AI 操作也能跳转到对应任务。

## 交互含义

1. **资料是项目文件，不是 AI 员工列表。** 分类按内容，不按工种；文档可人工修改，也可由 AI 生成或修改后归档。
2. **素材以浏览和判断质量为主。** 属性随选择变化；针对素材的 AI 操作就近提供，不要求先离开素材库。
3. **用户选择的对象不等于全部上下文。** 当前文档与选中的素材表达修改目标或指定参考，Codex 仍自行检索其他所需内容。创作页不增加强制上下文勾选器。
4. **Beaver 不展示必须由用户操作的内部编排。** 任务、成果、反馈、回退是对外入口；Codex 如何拆分任务不在这轮界面中设计。
5. **解释移出工作区。** 常驻文本只保留内容、名称、属性、状态和操作；真实风险、未保存确认与错误不能删除。
