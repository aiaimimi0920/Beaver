# 游戏总览与基础设定锁

版本：0.1.10。目标是确认 UI 交互，不实现游戏重构业务。

## 入口与视觉

左侧第一项“总览”，创建、接管及重新启动后默认展示。采用用户截图中的核心字段关系，不复制其蓝白主题、商业美术、经营成本或人员系统。继续沿用 Loom 紧凑壳层、默认 1120 x 760 / 最小 960 x 680、186 / 52 侧栏和 50 顶栏。新增总览使用线性四格图标；展开与收缩时所有图标位置保持一致，设置仍在左下角。

0.1.10 移除原全宽表格和“总览”重复页标题。左上只有一行游戏名字，过长时省略并可悬停查看完整名称；左侧其余部分留空，不放占位卡或说明。右上是一整张独立设定卡，类别和主题有较大的语义线性图标，其下紧凑排列评级、大小、在线多人和风格。编辑开关、锁定状态和保存操作都在卡内；不改变整个应用的顶栏与侧栏。

## 二级卡牌选择

- 锁定时，六个设置齿轮禁用；开启编辑后才可打开对应弹窗。名字在左上原位编辑，不展开全页表单。
- 类别：64 张类别卡，已有旧卡牌类别按需保留。先选择“主类别”或“副类别”槽位，再点卡片；副类别可选“无副类别”，不得与主类别重复。主类别选择当前副类别时交换两者位置。
- 主题：49 张预设卡与一张自定义入口；自定义主题在弹窗内输入。类别和主题支持名称搜索、目录顺序/名称排序及空结果提示。
- 评级、大小、风格：分别用 3、4、6 张卡单选；评级和大小只展示当前选项的一段含义，不给每张卡堆叠长说明。
- 在线多人：独立容量弹窗，保留联机开关、架构、区域、人数和实例字段，关闭后仍保存原容量草案。
- 选择卡使用 Beaver 自绘线性 SVG 图标与信号黄选中态，附主/副类别或“已选择”文字标记；不复制参考游戏商业图标、解锁系统、提示数或经营分值。
- 弹窗正文独立滚动，底部“取消 / 应用”固定可见。点击“应用”只更新总览草稿，不保存数据库、不触发风险弹窗或任务；取消、关闭或 Escape 丢弃这次弹窗内的选择，并恢复入口焦点。
- 评级冲突、多人类别与联机要求、无效容量、自定义空主题在弹窗内阻止应用。整个设定仍需“保存设定”才写入数据库并显示强风险提示。

## 控件含义

| 控件 | 含义与约束 |
| --- | --- |
| 游戏名称 | Beaver 中的游戏展示名，去首尾空白后 1–80 字符；不改目录或 Godot `application/config/name` |
| 主 / 副类别 | 主类别必选；副类别可无，不与主类别重复，沿用既有 64 类目录 |
| 主题 | 单一预设或手动输入，不是多标签 |
| 游戏评级 | 全年龄 / 青少年 / 成年人创作目标，不是正式认证 |
| 游戏大小 | 独立 / 标准 / 大型 / AAA 制作复杂度目标，不是包体积 |
| 在线多人游戏 | 是否计划在线多人；启用后显示架构、人数、服务区域与实例规划，不表示已部署 |
| 表现风格 | 保留已有六种视觉目标，与其他基础字段一起锁定 |

编辑复用创建表单的类别、评级冲突、在线人数等校验；无效输入不能保存。服务器数值的限制不代表实现能力承诺。

## 编辑流程

1. 默认锁定。只读界面不渲染可编辑的基础字段，不能误点改值。
2. 主动开启“编辑设定”，允许名字原位编辑与卡内齿轮操作，并显示一句风险提醒。没有改动时不能保存。
3. 关闭开关且有改动时，弹出放弃确认；“继续编辑”保留草稿，“放弃修改并锁定”恢复已保存内容。
4. “保存设定”成功后重新锁定，并显示红色强提示“项目设定已更改，存在风险”，列出本次变化字段及不兼容风险。弹窗不自动过期，需点击“我已知晓”、关闭按钮或按 Escape 手动关闭。失败保留草稿，不显示成功风险弹窗。
5. 切换页面或项目保留各项目草稿，但返回总览重新锁定；已保存信息与草稿不会混展示。再次开启开关可继续。整个应用退出只保留已保存内容，草稿不是自动存档。
6. 已保存版本变化时，过期草稿禁止保存；确认“重新载入”后丢弃草稿，重新编辑。不会自动合并可能冲突的基础设定。

“项目设置 / 基本设定”改为“前往总览编辑”，保留功能规划选择；三个阶段和发行草案仍正常编辑，不需解锁基础设定。后端旧规划保存也拒绝修改基础字段，避免旁路误改。

## 数据和风险边界

- 名称与基础规划一次写入本地 SQLite，共用 `blueprintRevision`；未改动的提交不增加版本。
- `allowRiskyChanges: true` 是明确的调用契约，不是安全授权令牌；编辑锁用于防误操作，不防恶意代码。
- 总览草稿和其他规划草稿分开，避免“保存规划”替代基础设定风险提示。一个入口保存后另一个入口的旧草稿会过期并保留，需确认重新载入。
- 初次创建可设定全部字段；接管旧项目由已有方向或默认值初始化展示，不假装 AI 已分析完整游戏。
- 本版保存不修改游戏文件、路径、素材、玩家程序名称、旧 `beaver.project.json` 或任务上下文，不调用 Codex、不部署服务器。风险提示强调以后按新设定继续开发时可能不兼容，不声称当前操作已经重构游戏。
- 保存后提示不代表完成兼容性检查。未来实际应用新设定到游戏，必须通过明确的 AI 修改任务、回退链及人工验收。
