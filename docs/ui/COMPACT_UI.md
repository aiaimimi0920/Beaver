# 紧凑界面约束

2026-09-06 用户明确要求：减少二级子标题和解释型 UI，参考 Loom 的实际表现。此约束补充原设计系统，不更换颜色基线。

- 每页一个简短标题：任务、素材、功能块、设置。不要在上方再加英文分类标签、项目状态口号或营销式副标题。
- 侧栏仅保留品牌、折叠入口、工作区导航与左下角设置。运行任务数量按需显示在任务入口，不常驻空闲状态或版本号。项目只在顶栏选择一次；托盘行为放在关闭按钮提示与使用说明。
- 操作区直接展示输入和按钮。能用控件表达的行为，不再配一段解释。
- 任务列表和详情共用连续面板，以分隔线区分；空态使用单行状态，不重复宣传产品理念。
- 设置参考 Loom 的 `LoomSettingsSections.tsx`：平级折叠行、一个名称、必要状态、按需展开字段。折叠不丢失未保存输入。
- 功能块直接列名称、版本、用途和操作，更新规则按需展开，不占据首屏的大卡片。
- 素材保留清晰预览和反馈输入；图片框选通过操作提示说明。卡片预览使用原生按钮，多选框是独立控件，键盘可访问。
- 精简不等于隐藏故障：错误原因、冲突、回退后果、安装权限、云端计费未实现等必要信息仍必须可见或在相关操作时展示。
- 使用现有 Neuro 信号黄、信号绿及中性色，不增加一套主题。

实际参考位置：Loom `apps/desktop/src/App.tsx` 的紧凑侧栏和单页面标题，以及 `apps/desktop/src/components/settings/LoomSettingsSections.tsx` 的平级折叠分组。只读取并参考，没有修改 Loom。

验收使用真实 Electron 桌面，而非参考 HTML：默认内容区 1120 × 760，与 Loom 对齐；保留 Beaver 实际最小窗口 960 × 680。Loom 没有声明最小窗口，不能把该最小值写成上游规范。检查内部滚动、图片框选、键盘预览、设置草稿、弹窗焦点、Escape 恢复及真实窗口控制。

0.1.2 壳层尺寸固定为：侧栏 186px / 折叠 52px，顶栏 50px，品牌按钮 36px、标记 28px，导航行高 36px，底部入口距底边 9px。右上依次刷新、最小化、最大化或还原、关闭；关闭仍进入托盘。设置拥有自己的单一标题和服务来源切换，不再叠加外层页头。

0.1.5 补充：折叠按钮、任务、素材、功能块及底部设置图标，在同一窗口尺寸下展开、收缩、再展开时，其屏幕坐标和尺寸必须一致。品牌区使用固定 8px 左右内边距，导航按钮使用固定 3px 内边距；禁止在折叠选择器中重新定义左侧 padding 或对图标重新居中。折叠只改变侧栏宽度、文字与空隙，不移动图标列。默认窗口与最小窗口都需要真实坐标回归验证。
